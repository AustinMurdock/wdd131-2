By Location

This is the initial version of a location-based pokemon search tool.
Currently implemented web mechanics include:
- API calls to pokeapi.co,
- a table set to display information from those calls (set to pokedex ID numbers 1-151, Generation 1, Kanto region),
- descending multi-column sorting (click the headers),
- and parameters passed to subpages.
